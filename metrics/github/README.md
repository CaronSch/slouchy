# GitHub Metrics Snapshots

Snapshots are now stored as private GitHub Actions artifacts by:
`.github/workflows/github-metrics.yml`

Artifacts are named:
`github-metrics-<run_id>`

Download from:
`Actions -> Snapshot GitHub Traffic and Downloads -> run -> Artifacts`

Data included:
- Repository traffic (views/clones)
- Popular referrers and popular paths
- GitHub Release asset download counts (including `.dmg` totals)
